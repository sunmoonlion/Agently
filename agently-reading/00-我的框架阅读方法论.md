## 2. 六层模型

| 层 | 一句话 | Agently 交付物 |
|----|--------|----------------|
| 意图 | 它解决什么问题 | `01` |
| 边界 | 代码由谁拥有 | `03` |
| 契约 | 哪些行为必须稳定 | `04` |
| 组装 | 对象如何连接 | `05` |
| 执行 | 数据和控制如何流动 | `06` |
| 扩展设计 | 哪里可替换，为什么这样拆 | `07`、`08` |

## 3. Agently 阅读所得

1. 待验证：请求契约比 Agent 人设更接近框架核心。
2. 待验证：快照是隔离单次执行与可观测性的关键。
3. 待验证：Action 与 Execution Environment 分离的是调用能力和资源生命周期。
4. 待验证：TriggerFlow 的核心是 signal 与 execution lifecycle，不只是图。
5. 待验证：Agent extensions 提供场景语法，plugin 提供可替换实现。
