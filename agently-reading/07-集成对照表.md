# Provider 集成对照表

## Core 与实现

| 契约类型 | Core 负责 | 默认实现负责 |
|----------|-----------|------------|
| ModelRequester | 输入输出协议 | Provider URL、鉴权、payload、流事件 |
| ResponseParser | 解析入口与结果消费 | JSON 修复、代码围栏、特定格式解析 |
| PromptGenerator | 标准 Prompt 数据 | 文本与 schema 描述生成 |
| ActionExecutor | 分发契约 | 函数、MCP、Python、Bash 等执行 |
| EnvironmentProvider | 生命周期协议 | startup、health check、reuse、release |
