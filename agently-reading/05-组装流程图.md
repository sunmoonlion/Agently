# Agently 组装流程图

## 1. import 时

```text
import agently
  -> import base.py
  -> load default settings
  -> create global PluginManager
  -> register default plugins
  -> create EventCenter and hookers
  -> create Action / Environment / Approval / Skills / Workspace managers
  -> define Agent = Extensions + BaseAgent
  -> Agently = AgentlyMain()
```

## 2. 创建 Agent

```text
Agently.create_agent()
  -> AgentlyMain.AgentType(...)
  -> Agent
       = StreamingPrintExtension
       + SessionExtension
       + SkillsExtension
       + WorkspaceExtension
       + ActionExtension
       + ...
       + BaseAgent
```

## 3. 一次链式请求

```text
agent.input(...)
  -> request-scoped AgentTurn
  -> ModelRequest(parent settings/prompt/handlers)
  -> write Prompt slots
  -> AgentTurn.start()
  -> active AgentOrchestrator plugin
  -> AgentExecution
  -> ModelResponse
```

## 4. Provider 选择

```text
settings["plugins.ModelRequester.activate"]
  -> PluginManager.get_plugin("ModelRequester", name)
  -> plugin(prompt, settings)
  -> generate_request_data()
  -> request_model()
```

默认激活 `OpenAICompatible`，但激活项由 Settings 决定。

## 5. Action 组装

```text
agent.use_actions(...)
  -> request/agent action declarations
  -> Action Runtime plans calls
  -> Action Dispatcher resolves executor
  -> Environment Manager prepares dependencies
  -> ActionResult records
  -> results return to model loop
```

## 6. 关键问题

| 问题 | 当前答案 |
|------|----------|
| 配置是 eager 还是 lazy？ | 默认插件在 import 时注册；具体 Provider 在响应执行时实例化 |
| Prompt 何时冻结？ | `ModelResponse` 构造时复制 |
| Agent 能力来自哪里？ | BaseAgent + 多个 Agent Extension |
| 工作流定义和运行是否分离？ | 是，TriggerFlow 与 Execution 分离 |
