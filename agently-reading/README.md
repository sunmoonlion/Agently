# Agently 源码阅读训练

> 面向 Agently 4.1.3.5 的六层源码阅读项目。
> 跨天续接时先读：`00-当前进度与续接.md`

## 目标

这套材料不是 API 教程，而是训练以下能力：

1. 30 分钟内画出陌生框架地图。
2. 15 分钟内定位模型、Action、执行环境或工作流扩展点。
3. 1 小时内跟完公开 API 到模型响应的主链路。
4. 根据代码证据解释分层、快照、插件和生命周期设计。
5. 在阅读前先做预测，再用源码验证。

## 核心判断

Agently 的中心不是多智能体对话，而是 AI 应用运行时：

```text
Prompt + Output Contract
          |
      AgentTurn
          |
    Agent Execution
          |
     ModelRequest
          |
 ModelRequester Plugin
          |
    Model Provider
```

Action、Skills、Dynamic Task、TriggerFlow 和 EventCenter 围绕这条请求主链提供能力。

## 每日流程

1. **Task 1 读**：只读当前层需要的材料。
2. **Task 2 练**：定位、画图、跟栈或写最小扩展。
3. **Task 3 整理**：更新交付物、日志和误判复盘。

阅读动作使用 QPSVCR：

- `Q` Question：先写问题。
- `P` Predict：读前预测。
- `S` Search：用 `rg` 定位。
- `V` Verify：用测试或调用点验证。
- `C` Connect：连接上下游。
- `R` Retell：闭卷复述。
